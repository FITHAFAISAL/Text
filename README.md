Innu njan oru katha parayunnilla. Ennekaal anubhavasampathulla ningalodu 2 cheriya kaaryangal maathram chodhikkam:
Kazhinja 2 divasam njan paranjathil enthenkilum kaaryam undo ennu aarkkengilum thonniyo? Sheriyano thetto ennu aalochicho?
Sheriyaanennu thonniyenkil, nammal oru theerumaanam edutho? "Iniyenkilum prashnangal kandu pedichu maari nilkkilla, aarelum vannu maatti tharum ennu karuthi kaathirikkilla, ente vazhi njan thanne theerkkum" ennu?
Nammal aadyathe step edukkathidatholam kaalam, oru velichavum thaniye varilla. Tunnel-inte end-il aarelum konduvarunna velichathekaal, nammal thanne aadyam iranguka ennullathaanu kaaryam.
 * Thinking Point:
   "Prashnangal varumbol 'vidhi' ennu paranju kaathirikkukayano, atho iruttil aadyathe adu vekkunna aa velichamaayi nammal thanne maaraano?"
