Innale namma oru student-nte cheriya candle-ine patti paranju. Innu oru manushyan thaniye oru kaadu thanne undakkiya real story parayaam—Jadav Payeng, India-yude 'Forest Man'.
1979-il, Assam-ile Brahmaputra nadikarayil valiya oru flood vannu. Vellam irangikkazhinjappol, kure paambukalum jeevikalum choodu sahikkaathe, nizhalo maramo illaathe manalparappil kidannu chathu veenathu 16 vayassulla Jadav kandu. Athu kandu manassu thakarnna Jadav naattukaarodu chodichu, "Namukku ivide kure marangal nattu koodedo?" Pakshe ellarum paranju, "Ee manalparappil onnum valarilla, athu nadakkatha kaaryamaanu, aaraa ippo athinokke iranguka?"
Ayaalkku venamenkil government-ine kuttam parayamayirunnu, forest department onnum cheyyunnilla ennu paranju baakki ellavareyum pole kayyum katti nokki nilkkaamayirunnu. Pakshe ayaal aareyum kaathu ninnilla.
Dharalam tharippazhayaaya aa manalparappil, Jadav ororo bamboo thaikaal nattu thudangi. Oru aalu, single hands kondu 30-40 varsham continuous aayi marangal nattu pottichu. Innu athu 1300 acres-il kooduthal valuthaaya, aanakalum tiger-ukalum ulloru valiya dharalam kaadaanu—'Molai Forest'.
Chuttum ulla lokam iruttanu, oru change-um ivide nadakkilla ennu paranju aalukal poya idathaanu ayaal thaniye oru velichamaayi maariyathu.
 * Thinking Point: "Chuttum ulla aalukal 'nadakkilla' ennu paranju pinmaarumbol, 'ente kondu ithra maathrame cheyyaan pattu' ennu karuthi oru cheriya thaikanu vekkaan enkilum namma tayyaraano?"
